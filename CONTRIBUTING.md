# Contributing to DonutShards

Thank you for your interest in contributing.

## How to contribute

1. Open an issue to discuss significant changes before starting large work.
2. Fork the repository and create a feature branch from `main`.
3. Keep changes focused; match existing code style and conventions.
4. Add or update tests when behavior changes.
5. Run `./gradlew test` (or `gradlew.bat test` on Windows) before opening a pull request.
6. Open a pull request with a clear description and link any related issues.

## Development setup

- Java 21 toolchain (see `build.gradle.kts`).
- `./gradlew build` compiles and runs tests; `./gradlew release` produces the release artifact.

## Code of conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md). By participating, you agree to uphold it.
